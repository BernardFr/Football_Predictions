Season predictions

Updated ${updated}

How good this season's predictions were. Each game is predicted before kickoff with only the results known at that time (a walk-forward backtest), then graded on its result.

Grade = how much better the predicted score probabilities did than the league's usual scorelines (the previous seasons): 0 = no better, +100 = certain and right, below 0 = worse. It weighs the result (50%), the goal difference (25%) and each side's goals (25%). A group of games (a team, a matchweek, the season) adds up the scores of its games first, so one odd game does not dominate it.
