Updated 26 Nov 2026, 10:56 PST

How good this season's predictions were. Each game is predicted before kickoff with only the results known at that time (a walk-forward backtest), then graded on its result.

Grade = how much better the predicted score probabilities did than the league's usual scorelines (the previous seasons): 0 = no better, +100 = certain and right, below 0 = worse. It weighs the result (80%) and each side's goals (20%). The goal difference skill is shown but not weighted. A group of games (a team, a matchweek, the season) adds up the scores of its games first, so one odd game does not dominate it.
